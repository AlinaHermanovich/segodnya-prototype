# Сегодня — прототип горящих остатков

Тот же макет, что в Grok: слева меню **Макеты**, справа телефон.

## Как увидеть дизайн

1. Сайт: https://alinahermanovich.github.io/segodnya-prototype/
2. Или скачай `index.html` и `app.js` в одну папку и открой `index.html` на компьютере (окно шире 800px). На телефоне меню уходит в кнопку «Кадры».

Страница кода на GitHub — это не дизайн, а исходник.
