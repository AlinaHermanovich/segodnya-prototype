# Сегодня — прототип горящих остатков

Кликабельный макет для супераппа: клиент забирает вечерний бокс, заведение выкладывает остаток.

Не продакшен. Оплата только на кассе. Без столиков и полного меню.

## Как открыть

1. Скачайте репозиторий и откройте `index.html` в браузере.
2. Или включите GitHub Pages: Settings → Pages → Deploy from branch `main` / root.

Живая страница после Pages: https://alinahermanovich.github.io/segodnya-prototype/

## Что смотреть

- **Живой сценарий** — бронь №14, выдача на кассе, время «До / Окно / После».
- **Кадры** слева (на телефоне кнопка «Кадры»): C1–C6 клиент, B1–B4 заведение.
